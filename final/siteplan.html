Morning Bliss Site Plan

WDD 231: Web Frontend Development I — Final Project Plan

1. Site Name

Name: Morning Bliss

Reasoning: "Morning Bliss" represents a fresh, vibrant, and reliable start for small business owners looking to bring their digital presence to life. It serves as both a developer portfolio and a client web application portal.

Optional domain availability: morningblissweb.com

2. Site Purpose

The site serves a dual purpose: it acts as my professional web developer portfolio showcasing projects to recruiters and hiring managers, while operating as an interactive portal for potential business clients to explore services (custom web development, REST API integration, and WCAG AA accessibility audits) and compute instant cost and timeline projections using an interactive scope estimator tool.

3. Target Audience Scenarios

  • Scenario 1 (Potential Client): "How much will it cost and how many days will it take to build a 3-page custom web application with API integration for my small business?"
  • Scenario 2 (Tech Recruiter / Hiring Manager): "Where can I view Buyannemekh's recent JavaScript projects, live public GitHub repository statistics, and code repositories?"

  • Primary Color (#1E293B - Slate Navy): Used for primary headings, body text, header backgrounds, and structural section boundaries.
  • Accent Color (#F59E0B - Sunshine Gold): Used for call-to-action buttons, interactive highlights, focus rings, borders, and active links.
  • Background Canvas (#FAFAF9 - Warm Cream): Light, modern, accessible background canvas to maintain readable contrast.

5. Typography

  • Heading Font (Poppins): Applied to all major headings (<h1>, <h2>, <h3>) for a structured, geometric appearance.
  • Body Font (Inter): Applied to all paragraph text, list items, forms, and technical project details for clean legibility across devices.

6. Responsive Wireframe Sketches

Simplified structural wireframe representation for small (mobile) and larger (desktop) viewports:

Small Viewport (Mobile View - 320px to 640px)

Single column stacked layout with collapsible hamburger navigation menu, full-width card list, and stacked call-to-action buttons.

Larger Viewport (Desktop View - 1024px+)

Horizontal header navigation bar, split-screen hero section, multi-column CSS Grid card arrangements, and side-by-side scope estimator display.
